# 我的網站開發展示（GitHub Pages 版）

- **公開首頁**：展示公開網站專案（目前收錄「台灣中古車實價趨勢與世代資料庫」）。
- **私人入口**：透過 `PBKDF2 + AES-GCM` 瀏覽器端加密保護，原始碼中**不含**明文密碼與私人網址，輸入密碼後才會解密顯示。
- **動態網頁風格**：互動粒子連線背景、極光光暈、3D 傾斜聚光燈卡片。

## 如何開啟 GitHub Pages

1. 進入 `https://github.com/bossliugen/GENWeb` 的 **Settings** → **Pages**。
2. 在 **Build and deployment** → **Source** 選擇 **Deploy from a branch**。
3. Branch 選擇 `main`、資料夾選擇 `/ (root)`，點擊 **Save**。
4. 等待約 1 分鐘即可透過 `https://bossliugen.github.io/GENWeb/` 瀏覽。
